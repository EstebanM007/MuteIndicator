# Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/es/).

## [1.0.0] - 2026-08-24

### Added
- ✅ Indicador visual de micrófono silenciado en esquina inferior derecha
- ✅ Detección automática cada 100ms
- ✅ Menú contextual en bandeja del sistema
- ✅ Soporte para Windows 10/11
- ✅ Documentación XML completa
- ✅ Manejo robusto de errores
- ✅ Aplicación optimizada para gaming
- ✅ Executable standalone (1.36 MB)

### Features
- Círculo rojo translúcido indica micrófono silenciado
- Sin interfaz intrusiva - pequeño indicador discreto
- Transparente a clics - no interfiere con otros programas
- Caché de dispositivos para máximo rendimiento
- Dibujado optimizado con brush reutilizable
- Compilación ReadyToRun para startup rápido
- TieredCompilation para optimización a runtime

### Performance
- CPU: < 0.5%
- RAM: 40-50 MB
- Latencia: 100-150ms
- Tamaño: 1.36 MB

### Documentation
- README.md con guía completa
- QUICKSTART.md para inicio rápido
- GAMING_EDITION.md con detalles técnicos
- RELEASE_NOTES.md con historial de cambios
- Documentación XML en código fuente
- Ejemplos de uso

## Notas de Versión

### v1.0.0 - Gaming Edition
**Lanzamiento Inicial - Optimizado para Gaming**

Una aplicación ligera y rápida para indicar visualmente el estado del micrófono.
Perfecta para gamers, streamers y usuarios de videollamadas.

**Características principales:**
- Detección ultra-rápida (100ms)
- Consumo mínimo de recursos (< 0.5% CPU)
- Totalmente portable (ejecutable único)
- Sin configuración requerida
- Interfaz no intrusiva
